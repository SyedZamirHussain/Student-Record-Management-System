# Student Record Management System

A C++ console-based Student Record Management System using file handling.

## Features

* Add Student
* Display Students
* Search Student by Roll Number
* Calculate Average Marks
* Find Student with Highest Marks
* Exit

## Concepts Used

* C++
* Functions
* Loops
* Conditional Statements
* File Handling
* `ifstream`
* `ofstream`
* `getline()`

## Data Storage

Student records are stored permanently in a text file named `students.txt`.
